# Aplikasi Enkripsi PDF (AES)

Repositori ini berisi implementasi program kriptografi untuk melakukan enkripsi dan dekripsi pada file dokumen PDF menggunakan algoritma **AES (Advanced Encryption Standard)** dengan mode **CBC (Cipher Block Chaining)**. 

Program ini dikembangkan menggunakan bahasa pemrograman Python dan memanfaatkan antarmuka baris perintah (CLI) interaktif.

## 🛠️ Prasyarat (Prerequisites)

Sebelum menjalankan program, membutuhkan *library* pihak ketiga yaitu `pycryptodome`.

Untuk menginstal *library* yang dibutuhkan, jalankan perintah berikut di terminal:

"pip install pycryptodome"
